# Calculate annual income tax

Use this guide to run the retained Australian 2025–26 annual income tax
calculator from TypeScript.

## Before you start

- Install the SDK with [Install the SDK](../start/install-the-sdk.mdx).
- Use `au.incomeTax.annual` for the common plain SDK path.
- Pass taxable income as `Money` in cents.

## Steps

1. Import `aud` and the AU SDK helper.
2. Convert taxable income to a `Money` value.
3. Call `au.incomeTax.annual`.
4. Read `liability` and the report ledger.

## Example

```ts
import { Cents, aud } from "@taxkit/core/primitives";
import { au } from "@taxkit/sdk/au";

const report = await au.incomeTax.annual({
  taxableIncome: aud(Cents.make(9_000_000)),
});

console.log({
  kind: report._tag,
  liabilityCents: report.liability.cents,
  components: report.ledger.components.length,
});
```

## Verify the result

Expected output:

```json
{
  "kind": "AnnualTaxReport",
  "liabilityCents": 1958800,
  "components": 3
}
```

The liability value is cents. `1958800` means $19,588.00. This example is
unchanged in rules-au-income-tax/1.0.1, which corrects the 2025–26 Medicare
thresholds to $28,011 and $35,013. The annual calculator covers the resident
income-tax rates, low income tax offset and single-person Medicare levy without
the seniors and pensioners tax offset. Family reductions, exemptions, surcharge
and student loan repayments are not included. This example is not a complete
tax-return assessment or proof that a deployed installation has been updated.

## Handle errors

Use `TaxKit.safe.calculate` when you need a result value:

```ts
import { Cents, aud } from "@taxkit/core/primitives";
import { TaxKit } from "@taxkit/sdk";
import { au } from "@taxkit/sdk/au";

const result = await TaxKit.safe.calculate(au.calculations.annualIncomeTax, {
  taxableIncome: aud(Cents.make(9_000_000)),
});

if (result._tag === "TaxKitFailure") {
  console.error(result.error.message);
}
```
