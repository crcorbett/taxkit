# Changelog

Use this page when you need release history after a version has been applied.

## Current changelog sources

| Source                                                           | Owns                                                                 |
| ---------------------------------------------------------------- | -------------------------------------------------------------------- |
| [`CHANGELOG.md`](../../../CHANGELOG.md)                          | Repository-level release summary and package changelog index.        |
| [`apps/api/CHANGELOG.md`](../../../apps/api/CHANGELOG.md)        | API app release notes.                                               |

## Current release

The `taxkit` SDK is the public npm package; all other workspace packages remain
private. The SDK changelog records its applied package changes, and the root
changelog provides the repository summary. A changelog entry or package
version does not establish public availability: check the npm registry version
and tags for the SDK, and deployment readback for the Website and API.

## Pending changes

Before a release is cut, inspect pending Changesets:

```sh
bun run changeset:status
```

Do not copy pending Changeset text into a public changelog by hand. Apply the
pending changes with `bun run version-packages` only during release preparation.
