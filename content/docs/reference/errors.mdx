# Error reference

`calculateSafe` returns native `Result`: `Success` carries `success`; `Failure`
carries `failure`. Expected local calculation errors are `CalculationError`;
explicit `decodeInput` reports `InputValidationError`. The plain Promise host
adds safe unexpected, closed-client and disposal errors. Native Effect keeps
its defect and interruption semantics.

Money constructors and arithmetic return `MoneyError`, with closed reasons for
format, fractional cents, non-finite input, range, negative input and overflow.

## HTTP errors

The generated HTTP client receives declared calculator failures in
`CalculatorApiErrorEnvelope`. Input issues have fixed messages and bounded paths;
rejected amounts, opaque causes and private diagnostics are excluded.

```json
{
  "error": {
    "_tag": "InputValidationError",
    "message": "Invalid calculator input.",
    "issues": [
      {
        "path": ["payload", "facts", "grossPay"],
        "message": "Invalid input value"
      }
    ],
    "truncated": false
  }
}
```

| Error                               | Handling                                            |
| ----------------------------------- | --------------------------------------------------- |
| `InputValidationError`              | Show safe field issues.                             |
| `UnsupportedCalculatorContextError` | Select a supported calculator edition.              |
| `UnsupportedCalculatorError`        | Correct the request identity.                       |
| `CalculationError`                  | Inspect its rule, graph or output-invariant reason. |
| `CalculatorCapacityExceeded`        | Retry manually when work finishes.                  |
| `CalculatorOperationTimedOut`       | Retry manually.                                     |
| `CalculatorRateLimited`             | Wait for `Retry-After`, then retry manually.        |
| `CalculatorAdmissionUnavailable`    | Retry manually when the service is available.       |

Retrieve the calculator schema endpoint for descriptor-backed field guidance.
See [API errors](../api/errors.mdx) and [validation](../guides/handle-validation-errors.mdx).
