# SDK reference

| Import                | Owns                                                                            |
| --------------------- | ------------------------------------------------------------------------------- |
| `taxkit`              | `calculate`, `calculateSafe`, `run`, `createClient`                             |
| `taxkit/au`           | Named conveniences and complete AU calculator definitions                       |
| `taxkit/au/schemas`   | Scenarios, facts, parameters and checked report codecs                          |
| `taxkit/effect`       | `calculateReport`, `calculateRun`, `decodeInput`, `TaxKitService`, `TaxKitLive` |
| `taxkit/au/effect`    | Native programs, fact services, rules and rule-pack Layers                      |
| `taxkit/money`        | Synchronous native Result operations and Money codecs                           |
| `taxkit/money/effect` | Lazy Effect money operations                                                    |
| `taxkit/schemas`      | Shared calculator, metadata and error Schemas                                   |
| `taxkit/core`         | Engine, rule and fact definition contracts                                      |
| `taxkit/http`         | Native generated HTTP client contracts                                          |
| `taxkit/testing`      | Engine substitution support                                                     |

All paths belong to the single `taxkit` package. Both interfaces execute the same owning programs.

```ts
import { calculate } from "taxkit";
import { AuAnnualIncomeTaxCalculation } from "taxkit/au";
import { AnnualTaxScenarioInputSchema } from "taxkit/au/schemas";
import { Cents, Money, NonNegativeMoney } from "taxkit/money";

const taxableIncome = NonNegativeMoney.make(
  Money.fromCents(Cents.make(9_000_000))
);
const input = AnnualTaxScenarioInputSchema.make({ taxableIncome });
const report = await calculate(AuAnnualIncomeTaxCalculation, input);
report.liability.cents;
```

```ts
import { Effect } from "effect";
import { AuPayTakeHomeCalculation } from "taxkit/au";
import { TakeHomeScenarioInputSchema } from "taxkit/au/schemas";
import { fromDecimal, nonNegative } from "taxkit/money/effect";
import { calculateRun, TaxKitLive } from "taxkit/effect";

export const program = Effect.gen(function* () {
  const grossPay = yield* fromDecimal("3462.00").pipe(
    Effect.flatMap(nonNegative)
  );
  const input = TakeHomeScenarioInputSchema.make({
    grossPay,
    period: "fortnightly",
    taxFreeThresholdClaimed: true,
  });
  return yield* calculateRun(AuPayTakeHomeCalculation, input);
}).pipe(Effect.provide(TaxKitLive));
```
