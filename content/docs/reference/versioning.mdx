# Versioning

Use this page when you need to decide whether a docs, SDK, API or rule change
needs release metadata.

## Public version owner

The `taxkit` SDK owns the single public npm version. Its archive includes the
engine, calculators, Australian rules and HTTP contracts. Other workspace
packages remain private implementation owners; their versions do not form a
fixed public release group. `bun run version-packages` applies pending
Changesets to the affected packages and their dependants.

```ts
Production: release metadata

package-facing change
  -> Changeset
    -> bun run changeset:status
    -> bun run version-packages during release prep
    -> package changelogs and versions
```

## When to add a Changeset

Add a Changeset when you change package-facing behaviour:

- package exports
- package README behaviour or commands
- public SDK helper shape
- HTTP API request, response or status shape
- calculator schemas, errors, rule behaviour or package metadata

Name `taxkit` when an included module changes its public contract or distributed
files. Private app changes can carry their own changelog entries without
forcing an SDK release. Docs-only corrections and internal tools do not need
a Changeset when they leave public behaviour unchanged; state that rationale
in the pull request.

## Commands

```sh
bun run changeset
bun run changeset:status
```

Run `bun run version-packages` only when you intend to apply pending package
versions and changelogs.
