# Calculate annual income tax

Construct the non-negative annual scenario and execute its versioned definition.

```ts
import { calculate } from "taxkit";
import { AuAnnualIncomeTaxCalculation } from "taxkit/au";
import { AnnualTaxScenarioInputSchema } from "taxkit/au/schemas";
import { Cents, Money, NonNegativeMoney } from "taxkit/money";

const taxableIncome = NonNegativeMoney.make(
  Money.fromCents(Cents.make(9_000_000))
);
const input = AnnualTaxScenarioInputSchema.make({ taxableIncome });
const report = await calculate(AuAnnualIncomeTaxCalculation, input);
report.liability.cents;
```

Use exact decimal text parsing for external amounts. The report includes its ledger and a payable liability floored at zero.
