# Build a browser app with the HTTP API

Use this guide when a browser client needs the server to run a calculation.
The browser-safe SDK can run calculations on the device instead; compare the
choices in [Choose SDK or HTTP API](../start/choose-sdk-or-api.mdx).

## Before you start

- Run the API app locally or point at your deployed API base URL.
- Read [Authentication and deployment assumptions](../api/authentication-and-deployment-assumptions.mdx).
- Use canonical JSON values for tagged facts.

## Steps

1. Supply your API base URL as a `URL` value.
2. Construct canonical facts and explicit context/help Options for the typed API client.
3. Run the returned Effect at your application host.
4. Render the report or handle its typed failure channel.

## Example

```ts
import { Effect, Option } from "effect";
import { HttpApiClient } from "effect/http-api";
import * as FetchHttpClient from "effect/http/FetchHttpClient";
import {
  TakeHomeScenarioInputSchema,
  AuPayTakeHomeId,
  AuPayJurisdiction,
  AuPayTaxYear,
} from "taxkit/au/schemas";
import { TaxKitApi } from "taxkit/http";
import { fromCents, nonNegative } from "taxkit/money/effect";

export const calculateTakeHomePay = (baseUrl: URL) =>
  Effect.gen(function* () {
    const calculatorId = AuPayTakeHomeId.make("au.pay.take-home");
    const client = yield* HttpApiClient.make(TaxKitApi, { baseUrl });
    const amount = yield* fromCents(346_200).pipe(Effect.flatMap(nonNegative));
    return yield* client.calculatorApi.calculate({
      params: { calculatorId },
      payload: {
        calculatorId,

        payload: {
          facts: TakeHomeScenarioInputSchema.make({
            grossPay: amount,
            period: "fortnightly",
            taxFreeThresholdClaimed: true,
          }),
          jurisdiction: Option.some(AuPayJurisdiction.make("AU")),
          taxYear: Option.some(AuPayTaxYear.make("2025-26")),
        },
      },
    });
  }).pipe(Effect.provide(FetchHttpClient.layer));
```

## Verify the result

Call `calculateTakeHomePay(new URL("http://127.0.0.1:4000"))` for your local
API, or supply your deployed URL explicitly. The example has no default server
and reads no browser environment variables. The returned response contains
`report.netPay.cents` with the expected value:

```txt
270600
```

## Handle errors

For invalid facts, the API returns `CalculatorApiErrorEnvelope` with a
`CalculatorServiceError` in `error`. Use the schema endpoint when you want
descriptor-backed field help.
