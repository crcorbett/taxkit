# Product specs

This is the SPEC inventory and admission route. A SPEC lives here only while
its work is active, together with an entry in
[`../exec-plans/active/README.md`](../exec-plans/active/README.md). Delete the
SPEC and its task list when the work merges; Git and the pull request keep the
history, and the architecture, standards and package READMEs own the result.
