# Active exec plans

There is no active execution plan.

To start one, add `<topic>.md` in this directory for substantial work that
needs sequencing, follow [Implementing specs](../implementing-specs.md) and
link the plan from [`../../product-specs/index.md`](../../product-specs/index.md).
Delete the plan, its SPEC and task list when the work merges; Git and the pull
request keep the history.
